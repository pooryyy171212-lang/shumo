## 提交前格式核对清单

### 国赛
- [ ] 承诺书 / 编号页符合当届要求（不可出现校名人名）
- [ ] 页码、字号符合当届论文格式规范
- [ ] 参考文献格式统一
- [ ] AI 使用披露表按当届要求填写

### 美赛（2027 规则，25 页硬限制）
- [ ] **总页数 ≤ 25**（含摘要、目录、正文、参考文献、附录、**代码**；AI 使用报告不计入）
- [ ] 正文字号 ≥ 12pt
- [ ] 每页页眉：控制号 + 页码
- [ ] **全文匿名 + 清理 PDF 元数据**（作者名/校名）
- [ ] 单个 PDF < 25MB，文件名 = 控制号
- [ ] 不另附代码或数据文件（评委不收）
- [ ] Report on Use of AI：每次调用的工具版本、完整 prompt、完整 output —— **日志必须从第一天开始记**
