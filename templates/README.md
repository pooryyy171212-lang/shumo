## 提交前格式核对清单

### 国赛 CUMCM（2026 基线）

- [ ] 论文文件 PDF 或 Word，**≤ 20MB**（推荐 PDF）
- [ ] **电子版论文不含承诺书、编号页**，第一页就是摘要页
- [ ] A4，四边页边距 ≥ 2.5cm
- [ ] **不要目录**
- [ ] 正文（摘要页之后）**≤ 30 页**，附录在正文后、不计入这 30 页
- [ ] 摘要、正文、附录、元数据中无队员/学校/赛区身份信息
- [ ] 支撑材料：单独 RAR/ZIP，**≤ 20MB**，含全部可运行源码与自行收集的数据，清单写进论文附录
- [ ] 支撑材料无凭据/API key/身份信息
- [ ] AI：正文相应位置标注；参考文献列出工具名/版本/开发者/使用日期
- [ ] AI：**用则支撑材料须含 `AI工具使用详情.pdf`**（工具版本、用途阶段、关键 prompt 与回复、采用内容、人工修改）；**不用则在参考文献后附无 AI 声明**

### 美赛 MCM/ICM（2027 规则，25 页硬限制）

- [ ] **总页数 ≤ 25**（含摘要页、目录、正文、参考文献、注释、附录、**代码**）
- [ ] `Report on Use of AI` 放在 25 页之后，**不计页数、无页数上限**
- [ ] 正文字号 ≥ 12pt，英文
- [ ] 每页页眉：控制号 + 页码（如 `Team # 0000000, Page 6 of 25`）
- [ ] **全文匿名 + 清理 PDF 元数据**（学生/指导教师/学校）
- [ ] PDF **< 25MB**（官方原文“The attachment must be less than 25MB”），仅 Adobe PDF
- [ ] 文件名 = 控制号（如 `0000000.pdf`）
- [ ] 不另附代码或数据文件（评委不收）
- [ ] AI 披露三件套：行内引用 + 25 页内参考文献区列出工具 + 25 页后专章
- [ ] AI 日志：每次调用的工具版本、**完整 prompt 原文、完整 output 原文** —— 必须从第一天开始记
- [ ] 开赛后未向队友以外任何人求教，未公开发布题目或阶段成果

### 电工杯（2026 基线）

- [ ] 3 名同校队员 + 1 名指导教师，未跨校组队
- [ ] 参赛论文：单独 PDF 或 Word，**不压缩**
- [ ] 支撑材料：RAR/ZIP，**≤ 20MB**，含可运行源程序、自主查阅数据、较大中间图表
- [ ] 第 1 页封面：只写**报名序号 + 赛题论文题目**（题目不自拟）
- [ ] 第 2 页：题目、摘要、关键词；摘要**≤ 1 页**，无需英文翻译；此页起页脚中部连续编号
- [ ] 第 3 页起正文，**不要目录**，正文 **≤ 25 页**；附录页数不限
- [ ] 正文无队员/学校身份信息；删除凭据、API key 与无关调试文件
- [ ] 外部成果在正文标注并列入参考文献（书籍要写引用页码）
- [ ] 全文查重（重复率 > 40% 按雷同论文处理、取消评奖资格）
- [ ] AI 使用台账留存（官网未给专门披露格式，但不等于免披露）
