# 夏的数模

> 数学建模竞赛备战项目：**国赛 CUMCM / 美赛 MCM-ICM**，兼顾电工杯等延伸赛事。

这是一个个人数模工作台——把散落在各处的论文语料、模板、算法资料沉淀成一个**可持续更新的结构化仓库**，赛前不翻聊天记录，赛中不临时抱佛脚。

## 目录结构

```
shumo/
├── docs/            # 调研笔记、选品报告、赛事研究
├── resources/       # 论文语料索引（不搬运文件，只做导航）
├── templates/       # LaTeX 模板与格式核对清单
├── algorithms/      # 算法资源整理（对照去重后的精华）
└── README.md
```
