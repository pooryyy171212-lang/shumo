rootkiller6788/mathmodel-skill 的提交记录里写着：它的归属 metadata"仍指向原上游 **handsomeZR-netizen/mathmodel-skill**"（292★）。也就是说那个仓库本质是 handsomeZR-netizen 项目的重打包，连它自己的 LICENSE 都专门改过版权信息。**这再次确认它不是你的仓库，将来引用或搬运它的内容时，出处应该指向 handsomeZR-netizen 那份**（MIT 协议，搬运合法，但署名要给对）。

## 往"夏的数模"里搬什么：三条填充路线

**1. 论文语料层（最值钱，比赛时省时间）**
- 国赛：zhanwen/MathModel + yan-fanyu/CUMCM-Paper-And-SourceCode（2010–2024 论文+源码，星少但全）
- 美赛：dick20/MCM-ICM 的 16 年 O 奖论文 + GuangLun2000/COMAP-MCM-2026 补 2021 以后的
- 用法：不用搬进仓库（体积大、版权杂），在 README 里做成**索引清单**，按题型（评价/预测/优化/机理）标好哪年哪题值得精读

**2. 模板层（赛前一次配平）**
- 国赛格式：latexstudio/CUMCMThesis（2026 适配版）
- 美赛格式：personqianduixue/Math_Model 里有美赛模板，或 GuangLun2000 合集里带
- 你那个 skill 项目的 templates/latex/ 已经有底子，拿这两个核对一遍当届格式就行

**3. 算法资源层（质量比数量重要）**
- XiaoMaColtAI 的算法资源库 + zhanwen 的思维导图 + Lanrzip 的 Python 实现，三份对照，把重复的去掉、缺的补上
- HuangCongQing 的 MATLAB 实现作为 MATLAB 侧备份（美赛队里有人写 MATLAB 的话）

## 提醒两句

- **许可证先看再搬**：资料合集类仓库大多没写清楚论文版权，搬运需谨慎，做成链接索引最安全；代码类注意看 LICENSE 文件再复制。
- **星标≠时效**：Algorithms_MathModels 是 2018 年整理的，ravenxrz 那个已归档，参考可以，别直接当最新实践。
